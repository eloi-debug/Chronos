# v2.5 Batch 3A (political powers)

New tours (validated): **Egypt: Old, Middle and New Kingdoms** (6 chapters), **Ancient Macedonia** (6), **Imperial China: the major dynasties** (7), **The Mongol Empire and Mongolia** (6), **The Ottoman Empire** (6).

## Install
1. Unzip over the repo root (keep folders).
2. `python apply_batch3a.py`  (adds script tags; safe to run twice).
3. `node test/test.js && node test/smoke.js && node test/test-batch1.js && node test/test-batch2.js && node test/test-batch3a.js`
4. `python server.py`, hard refresh (Ctrl+Shift+R).

## Honest limits
- These five tours are built from outline-level encyclopedia sources. They explain sequence, turning points and disagreements, but several chapters say plainly that causes or details are not covered. They are not full histories.
- Egypt: dates differ by source (e.g. Old Kingdom start 2686, 2613 or 2543 BCE); New Kingdom and Hyksos detail is thin and partly from unrated sources.
- China: Xia is not asserted; the Five Dynasties/Ten Kingdoms, northern dynasties, Liao/Jin, and the Republic after 1912 are not covered.
- Mongol: no casualty or city-level detail; Mongolia after the 14th century is not covered.
- Ottoman: 17th to 19th centuries (reforms, wars, nationalism) and the WWI period, including the Armenian genocide, are not researched here; the end chapter says so.
- Macedonia: ancient kingdom only; not the modern state or its naming dispute.
- Not tested in a real browser.
